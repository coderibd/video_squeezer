# Roadmap

## Near term

- persist user settings between launches
- add retry-failed and skip-current controls
- show per-worker cards for concurrent jobs
- expose a structured application log
- add integration tests using small generated test videos

## Medium term

- resume incomplete queues after restart
- maintain a processing history database
- detect duplicate files without hashing entire multi-gigabyte videos unnecessarily
- package and sign a native `.app` bundle
- add automatic update support

## Later

- optional dark appearance
- saved compression profiles
- queue search and status filters
- cumulative space-saved analytics
- configurable subtitle, chapter, and metadata preservation policies
